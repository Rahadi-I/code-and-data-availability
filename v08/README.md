# v0.8 — dispersion guard, second classifier, feature-budget sensitivity

This folder is **separate from the v0.7 study that the current manuscript reports**. Nothing here changes
`paper/main.tex` numbers unless it is explicitly folded in; the v0.7 CSVs and figures stay as they are.

## Why

The v0.7 confirmatory run has one large failure: **EthanolConcentration, −0.11 minority F1** against SMOTE.
Its cause is identified: the guided walk over-disperses there by roughly an order of magnitude
(dispersion ratio ≈ 10 against a target of 1). The step bound `M*` is calibrated on the **bare** walk, but the
set that is finally accepted has additionally passed an origin filter, a local α bound, a purity vote and a
DTW-aligned step, so its **realised** dispersion can drift far from the calibration target.

## The mechanism (`guard.py`)

Measure the realised dispersion ratio ρ = tr Cov(φ(S)) / tr Cov(φ(X_min)) of the **accepted** synthetic set.

* ρ ≤ τ (τ = 2) → return unchanged; the guard is inactive.
* ρ > τ → shrink each synthetic path back along its own walk, toward the real minority sequence it started
  from: `s_i ← o_i + c (s_i − o_i)`, with `c ∈ (0,1]` found by a two-step secant search on `c ↦ ρ(c)`
  (GPF features are quadratic in the path, so `ρ ~ c²` is the initial guess). At most 3 feature evaluations.

Because the shrunk path stays on the segment between a real minority sequence and a point the walk already
certified as pure, shrinkage cannot leave the region the purity vote accepted — admissibility is preserved.

## Results

### 1. Second downstream classifier (task: does the ranking depend on the random forest?)

20 datasets, IR {5,10,20}, 3 seeds, N = 60 blocks. Same synthetic sets, two classifiers.

| method | rank (RF) | ΔF1 vs SMOTE (RF) | rank (ridge) | ΔF1 vs SMOTE (ridge) |
|---|---|---|---|---|
| signature-guided, aligned | **1.92** | +0.048 (p = 2e-4) | **2.08** | +0.023 (p = 4e-4) |
| GPF-guided, aligned | 2.26 | +0.042 (p = 1.4e-3) | 2.36 | +0.011 (p = 0.062) |
| GPF-guided, plain | 2.95 | +0.012 (p = 0.79) | 2.58 | +0.004 (p = 0.52) |
| SMOTE, raw | 2.88 | — | 2.98 | — |

Friedman p = 4.0e-6 (RF), 5.5e-4 (ridge); CD = 0.61. Mean F1 under ridge: 0.641 / 0.645 / 0.652 / 0.665.
**Verdict: the ordering survives.** The alignment main effect weakens under the linear model
(+0.030 → +0.007, p = 0.070); the guidance effect does not.

### 2. Feature budget (8 pilot datasets, N = 24, RF)

| N_SELECT | ΔF1 sig/aligned | ΔF1 gpf/aligned |
|---|---|---|
| 32 | +0.042 (p = 0.037) | +0.048 (p = 0.009) |
| 64 (paper) | +0.060 (p = 0.004) | +0.058 (p = 0.014) |
| 128 | +0.078 (p = 0.004) | +0.095 (p = 0.0006) |

**Verdict: stable, and 64 is the conservative choice** — the margin grows with the budget.

### 3. Dispersion guard — NEGATIVE RESULT

The guard works as a mechanism and fails as a remedy.

* fires on 30 % of cells (161/540) at τ = 2; median ρ 3.7 → 1.6; on EthanolConcentration ρ up to **373 → 2.0**
* admissibility improves: MMD to held-out minority **−0.062** on fired cells, **−0.154** on EthanolConcentration
* minority F1: **+0.006, p = 0.49** — no change
* the four losses are untouched: EthanolConcentration −0.11 → −0.10; guarded sig/aligned rank 1.98 vs 1.92 unguarded
* the trimming variant is worse: **−0.014, p = 6e-4** over 65 fired cells on 9 datasets (refilling the quota by resampling survivors reintroduces duplication)

**Revised diagnosis.** Over-dispersion in the range these walks produce is not what costs accuracy, and
neither is admissibility — the guard improves it without moving F1. Both statistics separate *synthesis
rules* from one another (raw-space vs feature-space synthesis differs by an order of magnitude more than
anything the guard corrects); *within* one rule they do not predict the residual loss. What predicts it is
the validity gate: three of the four losing datasets carry no more class signal in the guiding space than in
the raw space, and the fourth (GunPoint) is univariate. The remedy is to decline the method where the gate
is negative, not to post-process its output.

This is written up in the manuscript as §5.5 "Robustness, and a failed repair", and it replaces an earlier
speculative sentence ("the origin filter and purity vote should have rejected more") that this experiment
refutes.
